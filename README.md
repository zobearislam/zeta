# Zeta 0.2 — Montanza Playground

## Run it
1. Extract this ZIP.
2. Open `index.html` in a modern browser, or upload it to your GitHub Pages repository.
3. Edit the Zeta code and tap **Run program**.

## Layout
- Code editor at the top.
- Terminal/output panel on the left.
- Canvas/game stage on the right on wider screens.
- On narrow/mobile screens, the workspace panels stack vertically.

This is an early browser-based interpreted prototype. Test your examples in the browser before relying on it for a larger project.
